# 硬件选型

## 选型原则

- 大脑要能跑视觉/语音/未来 AI，且生态成熟 → 单板 Linux 计算机。
- 电机/传感器要硬实时、低成本、可分布到各模块 → 微控制器。
- 优先选社区资料丰富、配件易得的型号，降低 3D 打印 + DIY 的门槛。

## 模块1 推荐元器件

| 类别 | 推荐 | 备选 / 说明 |
|------|------|-------------|
| 大脑 processor | **树莓派 5（4GB+）** | 摄像头+语音+未来 AI 余量足；紧凑/低功耗场景可用 Pi Zero 2W（但算力弱） |
| 协处理器 | **ESP32-S3** | 比经典 ESP32 多算力/内存，自带 USB、为未来留余量；纯实时控制用经典 ESP32 也可 |
| 摄像头 | Pi Camera Module 3（CSI） | 或任意 USB 摄像头（即插即用、调试方便） |
| mic | I2S MEMS 麦克风（INMP441） | 远场/阵列可选 ReSpeaker HAT；省事可用 USB 麦克风 |
| speaker | I2S 功放（MAX98357A）+ 喇叭 | 或 USB 小音箱 |
| 电机 | **见下方"电机类型"** | 配套驱动按类型选 |
| 电机驱动 | TB6612FNG / DRV8833（直流） | 舵机直接 PWM；步进用 A4988/DRV8825 |
| 供电 | Pi 5 用 5V/5A USB-C；电机用独立电源域 | 逻辑与电机电源分离、共地 |
| 连接（模块1） | 树莓派 USB ↔ ESP32 | 点对点，无需自定义连接器 |

## 电机类型（待定参数）

用户描述为"一个电机"，未指定型号。架构按**可配置参数**处理，能力描述符里以 `endpoint.type`
区分（`motor.dc` / `motor.servo` / `motor.stepper`）。常见选择：

- **舵机（servo）**：位置控制简单、接线少，适合做"头部转动/朝向"这类有限角度动作。**桌面机器人首选**。
- **小型减速直流电机（dc + 驱动）**：连续转动，适合做转盘/底座旋转，需配 H 桥驱动。
- **步进电机（stepper）**：精确定位，但布线与驱动更复杂。

> 默认按舵机或小型减速直流电机准备，落地接线时据实选定。无论哪种，协议与软件结构都不变——
> 只体现在能力描述符的 `type/unit/range` 和固件的执行逻辑上。

## 未来模块（预判）

- **WiFi/联网**：Pi 5 自带 WiFi，阶段2直接用其无线接入并连 Mac mini；若主控换成无网络的方案才需独立 WiFi 模块。
- **移动模块**：轮式（2×直流+编码器）或差速底盘，新增一块 ESP32 节点接入总线。
- **手臂模块**：多舵机/步进，独立 MCU，能力描述符暴露各关节端点。
