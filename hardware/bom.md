# 物料清单（BOM）

选型理由见 [`../docs/hardware-selection.md`](../docs/hardware-selection.md)。

## 模块1 — 桌面机器人

| 项 | 元件 | 数量 | 备注 |
|----|------|------|------|
| 大脑 | 树莓派 5（4GB+） | 1 | 紧凑场景可换 Pi Zero 2W |
| 协处理器 | ESP32-S3 开发板 | 1 | 经典 ESP32 亦可 |
| 摄像头 | Pi Camera Module 3 (CSI) | 1 | 或 USB 摄像头 |
| 麦克风 | I2S MEMS (INMP441) | 1 | 或 USB 麦克风 / ReSpeaker HAT |
| 扬声器 | I2S 功放 MAX98357A + 喇叭 | 1 | 或 USB 小音箱 |
| 电机 | **待定**（舵机 / 减速直流 / 步进） | 1 | 见选型文档"电机类型" |
| 电机驱动 | TB6612FNG 或 DRV8833（直流）/ 直接 PWM（舵机） | 1 | 随电机类型 |
| 供电 | 5V/5A USB-C（Pi）+ 电机独立电源 | — | 逻辑/电机电源分离、共地 |
| 连接 | Pi↔ESP32 USB 线 | 1 | 模块1点对点，无需自定义连接器 |
| 结构 | 3D 打印外壳/支架 | — | 见 [`../cad/`](../cad/) |

> 未定项（电机及其驱动）在落地接线时据实补全；不影响软件结构。
